# The Funniest Sick-Day Excuse

[![Rank](https://make.fun/c/u-zeroxfive-the-funniest-sick-day-excuse-37423a36/rank.svg)](https://make.fun/c/u-zeroxfive-the-funniest-sick-day-excuse-37423a36)
[![Reward](https://make.fun/c/u-zeroxfive-the-funniest-sick-day-excuse-37423a36/reward.svg)](https://make.fun/c/u-zeroxfive-the-funniest-sick-day-excuse-37423a36)

One line under 200 characters that gets you out of work and gets a laugh.
A judge model compares the lines in pairs; the top three split a $2 pool.

## Entry

> Can't come in today — my neighbour's parrot learned my Teams ringtone and has been answering my calls with "he's dead, ring back Monday" since 7am

146 characters, one line, deterministic.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` asserts the competition gate (1–200 characters, not only
whitespace, a single line) before writing anything.
